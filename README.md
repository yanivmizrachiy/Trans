# טרנספורמציות וחפיפת צורות — חוברת ומאגר הוראה

[**פתיחת האתר**](https://transformations-math.vercel.app/) · [**החוברת — PDF, 65 עמודים**](https://transformations-math.vercel.app/book/transformations-complete.pdf) · [**מקור האמת היחיד**](./SOURCE_OF_TRUTH.md)

מאגר לחטיבת הביניים, בדגש על כיתה ז׳: **הזזה, סיבוב ושיקוף (היפוך)**, חפיפת צורות, סימטרייה ופעולות עוקבות כהעמקה. מותאם לעברית RTL, למכשיר נייד ולהדפסת A4.

## כללי ייחוס

- **משרד החינוך:** מציגים את דפי התוכנית המאומתים כצילום מקורי ללא שינוי; את התיאורים הפרשניים מסמנים כהסברים בלבד.
- **יצירות מקוריות:** 11 הדפים שנכתבו במיוחד למאגר נושאים את הלוגו של מחוז ירושלים ושתי שורות קרדיט: „הדף נערך ע״י יניב רז · מדריך מחוזי חט״ב בעיר ירושלים” ו„הדרכה במחוז ירושלים והעיר ירושלים - מנח״י, בהובלת איילת קריספין”, מתחת לקו זהב לכל רוחב הדף. אין להוסיף אותם לדפים מיובאים או למצגת משותפת.
- **חומרים קודמים:** ששת דפי razpages שומרים את זיקתם למקור. חומר שעובד ממצגות חיצוניות הוחלף בכתיבה מקורית (SOURCE_OF_TRUTH §כ); קבצים במקורות אחרים לא שונו.

## בנייה, בדיקות ופרסום

- `scripts/build_pdfs.py` — מפיק 20 קובצי דפי עבודה.
- `scripts/build_teacher.py` — מפיק 14 סיכומים ממוספרים ובודק עימוד.
- `scripts/build_official.py` — מאמת את חתימות עמודי המקור הרשמיים ומפיק PDF נפרד.
- `scripts/build_complete.py` — מרכיב את החוברת עמוד־עמוד בסדר הנושאי של `data/manifest.json`, עם סימניות ומספרי עמודים; `scripts/sync_book_docs.py` מייצר את סדר הקריאה מהמניפסט.
- `scripts/test_math.py`, `scripts/test_pedagogy.py`, `scripts/validate_site.py`, `scripts/visual_audit.py` — בדיקות חישוב, שאלות, ייחוס, קישורים ועימוד.
- `.github/workflows/build-pdfs.yml` ו־`.github/workflows/validate-site.yml` — בדיקות ובנייה אוטומטיות; האתר נפרס ב־Vercel מענף `main`.

**מצב מאומת:** תהליכי הבנייה והבדיקות עברו, ו־Vercel דיווח `READY`. [בדיקת HTTP ציבורית ובדיקת Chromium בנייד](https://github.com/yanivmizrachiy/Trans/actions/runs/41484572091) אימתה **82/82 משאבים ציבוריים** (כל דפי האתר, החוברת וחלקיה, דף הקריאה הרציף, 20 דפי העבודה, 20 קובצי ה־PDF, הנכסים ועשרת צילומי המקור) עם התאמת SHA-256 ל־GitHub, לצד RTL, חיפוש, סינון, תצוגה מקדימה ופעולות במעבדה. [בדיקת העקביות לאחר פרסום ה־PDF](https://github.com/yanivmizrachiy/Trans/actions/runs/41484572250) הסתיימה בהצלחה. נותרות הגהה אנושית מקיפה ובדיקת הדפסה מוסדית, ולכן אין לטעון להשלמה מוחלטת.
