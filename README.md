# טרנספורמציות — מאגר הוראה לחטיבת הביניים

אתר ממוקד בהזזה, שיקוף, סיבוב, סימטרייה וחפיפת צורות. כולל דפי עבודה שלמים עם שרטוטים, צפייה נוחה בטלפון והדפסה / שמירה כ־PDF.

**[פתיחת האתר](https://transformations-math-yanivs-projects-322b2b37.vercel.app/)** · **[מקור האמת היחיד](./SOURCE_OF_TRUTH.md)**

## התוכן
- **דפי עבודה:** `worksheets/349.html`, `350.html`, `351.html`, `352.html`, `385.html`, `549.html` — ייבוא מהמקור `yanivmizrachiy/razpages` בלי שינוי נוסח השאלות והסרטוטים; `worksheets/rectangles.html` — דף חקר על בסיס ההשתלמות.
- **מדריך למורה:** `docs/PEDAGOGY.md`.
- **שאלות ותשובות מתומצתות מהמצגת:** `docs/PRESENTATION_2026-10-21.md`.

- **כתובות והוכחות מקור:** `SOURCE_OF_TRUTH.md`.

## כללי המאגר
אין כיתובי דמו, אין חומר שאינו עוסק בטרנספורמציות, אין הצגת יצירה עצמאית בתור שאלה רשמית, ואין שינוי בריפואים המקוריים. לכל מקור יש ייחוס ומעמד אימות; `SOURCE_OF_TRUTH.md` הוא מקור המדיניות היחיד.

## תפעול
האתר בנוי כ־HTML/CSS/JS סטטי, ללא התחברות וללא צורך בשרת אפליקציה. פתיחת דף עבודה → כפתור **הדפסה / שמירה כ־PDF** → בחירת מדפסת או Save as PDF. כל הדפים נגישים גם דרך הקישורים באתר.

## התאמה לנייד
עברית RTL, עיצוב רספונסיבי, מסננים וחיפוש, תצוגה מלאה של דף ושמירת פורמט A4 בהדפסה.

## פריסה
פרויקט Vercel מחובר לריפו `yanivmizrachiy/Trans`. אין להציג אתר כפעיל לפני אימות תגובת HTTP של כתובתו והמשאבים.
