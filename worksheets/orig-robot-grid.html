הרובוט בגינה — בודקים פקודות

אזור השקיה משולש: A(−5,1), B(−2,1), C(−5,4). קו הבקרה הוא x=1.

בדקו שכל הזזה ושיקוף שומרים את אורכי הצלעות.

1הזזה ושטח

הזיזו את המשולש ארבע יחידות ימינה ושתי יחידות למטה. רשמו את שלוש התמונות וחשבו את שטח המשולש לפני ההזזה ואחריה.

2שיקוף בישר אנכי

שקפו את המשולש המקורי ביחס לישר x=1. מצאו את A′, B′, C′. האם שטחו וכיווניותו השתנו? נמקו.

3בודקים את הדוח

תחילה משקפים בישר x=1 ומסמנים את התמונה A′B′C′. לאחר מכן מזיזים את התמונה בווקטור (−5,−3) ומסמנים את התוצאה הסופית A″B″C″. מחשב המעקב מדווח: A″(2,−2), B″(−1,−2), C″(2,2). האם הדוח נכון? מצאו את התוצאה המדויקת והסבירו איזו תכונה הופרה.
