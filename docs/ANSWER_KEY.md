# מפתח תשובות למורה — טרנספורמציות

**שימוש:** למורה בלבד; קובץ זה קיים בריפו הציבורי, ולכן אינו מאגר תשובות סודי. מקור השאלות: מצגת קהילת מורים 21.10.2026; נדרשת הקפדה על הנמקה ועל הקשר בין הייצוגים.

## מלבנים חופפים
נתון `A(-3,-1), B(-3,3), C(2,3), D(2,-1)`.

| סעיף | תשובה מדויקת |
|---|---|
| הזזה `A→G(-3,-5)` | וקטור `(0,-4)`; `H(-3,-1), K(2,-1), L(2,-5)` |
| היקף | `2(5+4)=18` |
| שטח | `5×4=20` |
| קודקוד קבוע `P(2,-1)` בהזזה בלבד | 4 אפשרויות |
| קודקוד P וצלעות מקבילות לצירים | 8 אפשרויות — כי ניתן לבחור איזו מן הצלעות באורך 5 ואיזו באורך 4 לצד כל ציר |
| קודקוד P ללא הגבלת כיוון | אינסוף מלבנים שונים |
| הזזה `A→R(1,1)` | `(4,2)`; לאחר ההזזה `R(1,1), B'(1,5), C'(6,5), D'(6,1)` |
| סיבוב 90° סביב R | עם כיוון השעון או נגדו יתקבלו תמונות חופפות שונות |
| שיקוף לאחר הזזה | יש לציין במפורש את ישר השיקוף. למשל `x=1` או `y=1` |

**הבהרה:** בגרסה שבה התלמיד בוחר "מלבן חופף" ללא הגבלת הכיוון, תשובה "8" שגויה; התשובה אינסוף. התניה "בהזזה בלבד" אינה שקולה ל"צלעות מקבילות לצירים".

## נכון / לא נכון — 8 טענות מהמצגת
1. `A(0,3)` נשארת במקומה בשיקוף בציר `y` — **נכון**; הנקודה נמצאת על ציר השיקוף.
2. שיקוף המשולש `(1,1),(4,1),(1,3)` בציר `x` נותן משולש ישר-זווית — **נכון**; השיקוף שומר זוויות.
3. שיקוף אותו משולש בציר `y` מכפיל את שטחו — **לא נכון**; שטח המשולש נשמר.
4. אם `A(2,3)` משוקפת בציר `y`, אחר כך התמונה בציר `x`, ואחר כך שוב בציר `y`, אז `ABCD` מלבן שאינו ריבוע — **נכון**; קודקודים `(2,3),(-2,3),(-2,-3),(2,-3)`.
5. סיבובי `A(4,1)` סביב הראשית ב־90°, 180°, 270° יוצרים עם A ריבוע — **נכון**; ארבע נקודות בהפרשי 90° על מעגל סביב הראשית.
6. `A(2,1)`, תמונתה בסיבוב 180° והראשית יוצרים משולש שווה שוקיים — **לא נכון**; שלוש הנקודות קולינאריות, ולכן אינן יוצרות משולש.
7. סיבוב המשולש `(0,0),(3,0),(0,2)` ב־90° מכסה את המשולש המקורי — **לא נכון**; אין לצורה סימטרייה סיבובית של 90° סביב הראשית.
8. סיבוב משולש ב־180° שומר את שטחו ואת היקפו — **נכון**; סיבוב הוא איזומטרייה.

## זיהוי טרנספורמציה של משולש
מקור `A(4,1),B(7,1),C(4,3)`.

| יעד | הטרנספורמציה | תמונת הקודקודים |
|---|---|---|
| `DEF` | 90° נגד כיוון השעון סביב O | `D(-1,4), E(-1,7), F(-3,4)` |
| `GHI` | 180° סביב O | `G(-4,-1), H(-7,-1), I(-4,-3)` |
| `JKL` | שיקוף בציר x | `J(4,-1), K(7,-1), L(4,-3)` |
| `MNP` | שיקוף בישר `x=1` | `M(-2,1), N(-5,1), P(-2,3)` |
| `QRS` | הזזה `(-9,-9)` | `Q(-5,-8), R(-2,-8), S(-5,-6)` |

## קריטריונים לתשובה טובה
- **סיבוב:** אין לקבל כתיאור מלא רק "90°"; יש לציין את המרכז ואת הכיוון (או להוכיח שאינו משפיע במקרה של 180°).
- **שיקוף:** נדרש ישר שיקוף. "תמונת מראה" בלבד אינו מגדיר את ישר ההעתקה.
- **הזזה:** נדרשים כיוון ומרחק, או וקטור שקול. שינוי קודקוד אחד אינו מספיק כהנמקה שכל הצורה הוזזה באותה העתקה.
- **חפיפה:** יש להסביר כיצד הפעולה שומרת מרחקים וזוויות; שוויון שטח לבדו אינו מוכיח חפיפה.
- **סימטרייה:** אין להניח שקיימת סימטרייה רק משום שאפשר לייצר צורה חופפת חדשה.
